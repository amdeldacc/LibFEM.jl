Problem: 293 lines of abstract types, concrete structs, type aliases, and show methods that are never dispatched on. CONTEXT.md says: "documentation-only scaffolding." The interface is the code itself.

Solution: Delete types.jl, remove its include/export lines. Functions don't use it — nothing breaks.

  • — locality: no dead code to navigate around
  • — interface: shrinks by 7 export lines, 7 types
  • — leverage: zero — removing unused code doesn't enable anything. But it stops confusing readers who wonder "where is this dispatched?"
